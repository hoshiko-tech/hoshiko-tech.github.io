# Sushi restaurant — client intake template

An intake questionnaire for onboarding a sushi / Japanese restaurant client and
gathering everything needed to start building their website.

## Files

- **`intake-questionnaire.md`** — the questionnaire itself, written to be sent
  directly to the client (or filled in together on a call). It's tailored to the
  sushi genre: omakase/set courses, sake lists, allergens for raw fish, Tabelog
  and other listing sites, and an English/Japanese bilingual option.
- **`tally-form-fields.md`** — the same questionnaire as a build sheet for a
  **Tally** form (field labels, block types, and which are required), so clients
  can submit everything in one place. Also works for Google Forms.

## How to use it

- **Sending it to the client:** paste it into an email or message, share it as a
  doc, or export to PDF. Sections are self-contained, so you can also send it a
  couple of sections at a time if that's easier for them.
- **On a call:** use it as a script so nothing gets missed, and fill in the
  **→** fields as you go.
- Questions marked **⭐** are the essentials needed before building can start;
  the rest improves the result but can follow later.

## Reusing for future clients

This is a genre template. To adapt it for another restaurant type (ramen,
izakaya, cafe, etc.), copy the folder and adjust the menu section (section 5) and
the story/concept prompts (section 2) — those are the most cuisine-specific
parts. The structure works for most small hospitality sites.

## Mapping answers to a build

The answers in section 10 ("What the site needs to do") line up with the tiers on
the [Simple Websites](https://www.hoshiko.tech/websites/) page:

- Single-page presence → **One-Page**
- Several pages, no live functionality → **Multi-Page**
- Online booking / ordering / accounts → **Advanced**
