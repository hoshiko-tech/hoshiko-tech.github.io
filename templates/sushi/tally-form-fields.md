# Sushi restaurant intake — Tally form build sheet

A field-by-field spec for rebuilding the questionnaire as a **Tally** form
(works the same for Google Forms — just map the block types). Build it once,
duplicate it per client.

## Setup in Tally (5 min)

1. Create a new form → give it a title like **"Website questionnaire — [Restaurant]"**.
2. Add the blocks below in order. Use **page breaks** between the numbered
   sections so it feels like a short multi-step form, not a wall of questions.
3. Mark the fields tagged **Required** below.
4. In **Settings → Email notifications**, turn on "Send me an email for each
   response" so submissions land in your inbox — that's what you paste to me.
5. Optionally **Settings → Confirmation** message: a friendly "Thanks! We'll be
   in touch shortly." Publish and share the private link with the client.

> Tip: turn on a **partial-submission** save or keep it short — restaurant owners
> are busy. File-upload blocks can be marked optional so they're never blocked.

Legend for block types: **Short** = short answer · **Long** = long answer ·
**Choice** = multiple choice (pick one) · **Checkboxes** = pick many · **Email**,
**Phone**, **URL**, **File** = Tally's dedicated blocks.

---

### Intro block (Text, not a question)

> Thanks for choosing to work with us! A few questions so we can build a site
> that really fits your restaurant. Skip anything you're unsure about — we can
> fill gaps on a call. ⭐ marks the essentials.

### Which "essentials" gate a build

The ✅ Required fields are the minimum to start: name, language, a menu, address,
hours, phone, email, and a point of contact. Everything else refines the result
and can arrive later.
